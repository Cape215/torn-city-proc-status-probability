# Torn City Proc Status Probability

A Tampermonkey script for Torn City that estimates the probability of triggering a weapon status effect based on previous non-proc hits.

## ⚙️ Features

* Calculates probability of next hit triggering a status effect
* Future projection (multiple attack scenarios)
* Visual UI panel (movable)
* Persistent position saving
* Statistical feedback on current streak

## 🧠 How it works

The script uses probability theory to estimate the likelihood of a status effect triggering after a number of failed attempts.

## 🚀 Installation

1. Install Tampermonkey
2. Create a new script
3. Paste the contents of `torn-proc-status-probability.user.js`
4. Save and reload Torn

## 📌 Usage

* Enter:

  * Base proc chance (%)
  * Number of hits without activation
* Click **Calcular**
* View real-time probability estimations
